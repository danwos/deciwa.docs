Agent-Skills¶

Status: Entwurf

Vorschläge von Claude – nicht verbindlich, bis Daniel sie freigibt.

Vorschlag: Zwei Skills im Agent-Skills-Format, im Repository mitgeliefert PROP_SKILLS_FORMAT
status: draft
refines: DEC_SKILLS
refined by: PROP_ROLLOUT_MIGRATE, Q_SKILL_INSTALL

skills/deciwa-work/SKILL.md und skills/deciwa-ask/SKILL.md, jeweils eine kurze Anleitung plus die CLI-Aufrufe, die sie nutzt. Die Skills rufen nur die CLI mit --json auf – nie die Dateien – und zeichnen als agent:<name>.

deciwa-work¶

  1. deciwa todo --json – die Aufgabenliste.

  2. Pro Aufgabe: das Element lesen und den Kommentar umsetzen, eine abgelehnte Aussage korrigieren oder das Element löschen.

  3. Nie ein Element im Zustand frozen bearbeiten; kollidiert eine Aufgabe mit einem Einfrieren, überspringen und das sagen.

  4. deciwa resolve <id> --note "<what changed>".

  5. deciwa request … --to <author> --question "Changed – OK?" für jedes Element, das er angefasst hat, damit der Mensch die Änderung sieht.

deciwa-ask¶

Schreibt der Agent etwas, bei dem er nicht sicher ist – eine erschlossene Formulierung, eine Zahl ohne Quelle –, schreibt er den Text so, wie er ihn für richtig hält, und setzt statt einer [CHECK]-Markierung eine Anfrage an dieses Element:

$ deciwa request 20_facts/company/founder.md --quote "since October 2026" \
    --to daniel --question "Is October 2026 the start date of the advisor role?"
