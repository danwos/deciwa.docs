File format¶

Status: draft

Proposals by Claude – not binding until Daniel approves them.

.deciwa/
├── config.toml                          optional settings
└── annotations/
    ├── 20_facts/company/founder.md.json one file per annotated source
    └── _web/danwos.dev/services.json    web pages without a mapped source
.deciwa/web-pages.json                   elements of the imported web pages
Proposal: One annotation file per source, deterministic JSON PROP_FILE_LAYOUT
status: draft
refines: DEC_DECIWA_FOLDER, DEC_GIT_COMMITTED
refined by: PROP_WEB_FILES

The path under annotations/ mirrors the source path relative to the folder that holds .deciwa/. The CLI writes sorted keys, two-space indent, one annotation after the other by creation time and a final newline – so Git diffs stay small and merge conflicts stay rare.
Proposal: Annotation structure PROP_ANNOTATION
status: draft
refines: DEC_FREEZE, DEC_THREE_MODES, DEC_VERDICTS
refined by: PROP_LATEST_WINS, PROP_SNAPSHOT
 
{
  "deciwa": "0.1",
  "source": "20_facts/company/founder.md",
  "annotations": [
    {
      "id": "k7q2m9xa",
      "kind": "feedback",
      "target": {
        "selectors": [
          {"type": "structural", "value": "md:paragraph:Career/Advisor#1"},
          {"type": "TextQuoteSelector", "exact": "advisor since October 2026",
           "prefix": "Daniel works as ", "suffix": "."},
          {"type": "TextPositionSelector", "start": 1204, "end": 1230}
        ],
        "fingerprint": "sha256:9c1e…",
        "snapshot": "Daniel works as advisor since October 2026."
      },
      "author": "daniel",
      "created": "2026-10-19T10:12:00Z",
      "verdict": "rephrase",
      "comment": "too stiff, say it like a person",
      "status": "open",
      "replies": []
    }
  ]
}

Proposal: While an element is unchanged, an author's latest verdict and latest rating replace the earlier ones PROP_LATEST_WINS
status: draft
refines: DEC_THREE_MODES, PROP_ANNOTATION

A misclick or a second thought must not pile up entries. As long as the element’s fingerprint is the same, a new verdict of the same author replaces the old verdict, and a new rating the old rating. Once the element changed, earlier annotations stay as history (that is how stale works). Notes and questions are never replaced; a comment that came with a replaced verdict is kept as a note. That is also how a freeze ends: the author gives another verdict (A freeze ends with a new ve... (DEC_FREEZE_BY_VERDICT)).
Proposal: The snapshot of the element text is stored with every annotation PROP_SNAPSHOT
status: draft
refines: PROP_ANNOTATION

Without it deciwa can tell that an approved or frozen text changed, but not what it looked like – and the freeze alarm must show the old wording (New verdict freeze (DEC_FREEZE)). The cost is some duplicate text in .deciwa/.
Proposal: A JSON Schema is the documented contract PROP_SCHEMA
status: draft
refines: DEC_CLI_MASTER

schema/deciwa-0.1.schema.json is published with the CLI and in these docs. The CLI validates every file it reads. A new major field means a new schema version; the CLI reads older versions and writes the newest.

config.toml¶

author = "daniel"                 # overrides git config

[adapters]
"**/*.md"  = "md"
"**/*.rst" = "rst"
"**/*.txt" = "text"

[needs]
directives = ["req", "spec", "dec", "prop", "question"]

[ignore]
paths = ["90_archive/**", "_build/**"]

Web sources¶

Proposal: Web pages without a source file are stored under their address PROP_WEB_FILES
status: draft
refines: PROP_FILE_LAYOUT, PROP_WEB_SOURCE

A page reviewed with the web script whose source is the fallback web:<host><path> is stored as annotations/_web/<host>/<path>.json; the path / becomes index, a port is written as _<port>, and the file keeps the address in its source field. deciwa import applies the rules of [web] first: a rule only counts when its file exists, so mapped pages land in the file of their source and everything else keeps its address. When a rule is added later, deciwa remap moves the annotations of _web/ to their source files.

An export from the web script carries the elements of its pages (selector, kind, label, text, fingerprint). The import keeps them in .deciwa/web-pages.json by address, so todo, show and status work without parsing HTML in Python; the selectors stay html:…, also for pages mapped to a Markdown file. Such an import replaces only the review data of the pages in the file, never the rest of the project.

 
[web]
site = "danwos.dev"                                   # optional, the host of the pages
sources = [                                           # optional, first match wins
  { url = "/",       file = "src/content/pages/index.md" },
  { url = "/blog/*", file = "src/content/blog/*.md" },
  { url = "/*",      file = "src/content/pages/*.md" },
]

Without [web] – or without .deciwa/ at all, when only the browser is used – every page keeps its address. site limits the rules to pages of that host; without it they apply to every host, also localhost while developing. A star in url stands for one or more parts of the address and replaces the stars in file in the same order.
